Method and limits

Evidence for this workload, with the counterexamples kept.

This is a post hoc explanation of a frozen experiment, not a claim of a new algorithm. Both partitions use the same inertial-flow heuristic and node bound, with different cut objectives. Their numbers of cells can differ. All comparisons retain the fixed pairs, including unreachable and identical-endpoint cases.

The original timing rotates methods but keeps query order fixed. Calls include cleanup of the previous query’s reusable state; group timings therefore include that context. Settled-node counts measure current search work, excluding cleanup. Runner processors differ across cities. The study establishes no external speed record.
